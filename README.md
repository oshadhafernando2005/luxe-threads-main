# Luxe Threads

Create a modern, stylish, colorful, and premium T-shirt shopping website with a mobile-first responsive design. The website should be simple, clean, and easy to navigate, with smooth animations and a luxury fashion look.

Home

Home Page

Modern hero banner with male and female models wearing T-shirts.

Two large category cards:

Shop Men

Shop Women

Below the categories, display featured T-shirt designs in a clean grid.

Simple footer with social media links and contact information.

Men's Collection

Display only men's T-shirt designs.

Include a filter button that opens a bottom sheet or side panel with:

Category

Size

Color

Price

Sort by (Newest, Popular, Price)

Show products as modern cards with:

Product image

Name

Price

Add to Cart button

Women's Collection

Use the same layout as the men's page but display only women's T-shirt designs.

Mobile Design

Prioritize the mobile experience:

Bottom navigation bar

Large touch-friendly buttons

Rounded cards

Simple product grid (2 columns)

Smooth scrolling and animations

Fast loading

Style

Use a modern fashion aesthetic with plenty of white space, rounded corners, premium typography, and vibrant accent colors. The interface should feel clean, elegant, and easy to use while keeping the focus on the T-shirt designs.
